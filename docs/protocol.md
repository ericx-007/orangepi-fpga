# UART 协议 P1

物理串口使用 115200、8 数据位、无校验、1 停止位。命令和应答均为 ASCII，以 LF 结尾。串口输入可包含 CRLF。

| 主机命令 | 作用 |
|---|---|
| `Q\n` | 查询当前状态 |
| `D01234567\n` | 原子写入 8 位十进制显示值并请求应答 |

应答格式：

```text
P1 01234567 0 0000 00000000
```

字段依次为协议标识、8 位显示数字、1 位十六进制按键掩码、4 位十六进制拨码值、8 位十六进制按下事件计数。

按键掩码的 bit 0–3 对应 K1–K4，1 表示按下。计数在消抖后的任一新按下边沿增加；同一时钟同时出现多个新边沿只增加一次。拨码每组 1 号为该组最低位；上下排在网页映射中调整。没有有效命令不会修改显示值，不完整命令在约 100 ms 后丢弃。

FPGA 应答表示显示寄存器和扫描逻辑的当前输入值。它不提供光学反馈，不能检测数码管损坏或外部接线错误。部署时需目视核对实体显示。
